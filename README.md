# Linux Troubleshooting Toolkit

## Overview

A Linux system monitoring and troubleshooting toolkit using Bash, Nginx, Docker and a Node.js backend.

## Features

- System information
- Disk usage
- Memory usage
- Process inspection
- Network inspection
- DNS testing
- Internet connectivity
- Service status
- Automated system reports
- Logging
- Nginx web interface
- REST-style backend endpoint
- Dockerized services
- Nginx reverse proxy
